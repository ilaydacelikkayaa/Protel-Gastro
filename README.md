# 🍽️ Protel Gastro

Protel Gastro, restoran sipariş ve masa yönetimi senaryosunu örnek alan bir iOS uygulamasıdır.

Bu repository içerisinde aynı uygulamanın **UIKit** ve **SwiftUI** olmak üzere iki farklı implementasyonu bulunmaktadır. Amaç, modern iOS geliştirme yaklaşımlarını öğrenmek ve iki framework arasındaki farkları uygulamalı olarak incelemektir.

# 🚀 Özellikler

* 🪑 Salon ve masa yönetimi
* 🍔 Kategori bazlı menü görüntüleme
* 🛒 Sepet yönetimi
* ➕ Ürün ekleme ve adet güncelleme
* 📝 Sipariş özeti
* 🧾 Adisyon (Bill) ekranı
* 💰 Ara toplam, servis ücreti ve genel toplam hesaplama
* ✅ Sipariş başarı ekranı
* 🚪 Masa kapatma işlemi
* 🔄 NavigationStack & NavigationPath ile ekran yönetimi (SwiftUI)

# 📱 Proje Yapısı

Repository iki farklı uygulamayı içermektedir.

```text
Protel-Gastro
│
```
